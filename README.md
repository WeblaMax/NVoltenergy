# NVoltenergy – site

Site static (HTML/CSS/JS, fără build) pentru NVoltenergy SRL – instalații electrice, Republica Moldova.

- `index.html` – prima pagină + intro animat cu moneda (logoul NVolt Energy)
- `servicii.html`, `preturi.html` (Ciclul 1, Ciclul 2, Lucrări intervenție), `contact.html`
- `despre.html`, `faq.html` – în meniul „Mai mult”
- `assets/` – logoul (simbol, logo complet, fața monedei), favicon

Rulare locală: `python3 -m http.server` și deschide `http://localhost:8000`.

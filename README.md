# NVoltenergy – site demo

Site static (HTML/CSS/JS, fără build) pentru NVoltenergy SRL – instalații electrice, Republica Moldova.

- `index.html` – prima pagină (ușoară) + intro animat cu moneda (se rulează la intrarea pe site; `Esc`/„Sari peste” îl oprește)
- `servicii.html`, `preturi.html`, `contact.html` – în meniul principal
- `despre.html`, `faq.html` – în meniul „Mai mult”
- Prețurile sunt **demonstrative** – de înlocuit cu cele reale.

Rulare locală: `python3 -m http.server` și deschide `http://localhost:8000`.
